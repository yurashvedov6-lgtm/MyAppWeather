# Описание бизнес-логики: Список городов Крыма и запрос погоды


- **Затронутые файлы:** `CrimeaCities.kt`, `MainActivity.kt`

---

## 1. Модель и источник данных (`CrimeaCities.kt`)

Файл отвечает за хранение справочника городов и их географических координат, необходимых для работы погодного API.

* **`data class City(name, latitude, longitude)`** — модель данных, описывающая один город. Хранит отображаемое название (`String`) и точные координаты широты и долготы (`Double`).
* **`val crimeaCities = listOf(...)`** — неизменяемый список из 10 объектов `City` (Симферополь, Севастополь, Ялта и др.).
* Объявлен на уровне пакета `com.example.appweather`, поэтому доступен в `MainActivity.kt` напрямую без дополнительных импортов.

---

## 2. Интерфейс и сетевая логика (`MainActivity.kt`)

Файл отвечает за отрисовку списка городов, обработку нажатий пользователя и получение актуальной погоды через Open-Meteo API.

### Отрисовка списка (`LazyColumn`)
`LazyColumn` работает как «конвейер» и создаёт элементы интерфейса только для видимой области экрана:
1. **`items(crimeaCities) { city -> ... }`** — запускает цикл по всем 10 элементам списка `crimeaCities`, передавая каждый объект в переменную `city`.
2. **`Button(...)`** — для каждого города создаётся кнопка на всю ширину экрана (`.fillMaxWidth()`) с вертикальным отступом `4.dp`.
3. **`Text(text = city.name)`** — выводит название текущего города внутри кнопки.

### Сценарий при нажатии на город (`onClick`)
1. **Запуск корутины (`scope.launch`)** — сетевой запрос выполняется асинхронно, чтобы не блокировать интерфейс приложения.
2. **Индикация статуса** — состояние `weatherText` обновляется на `"Загружаем погоду: ${city.name}..."`, что сразу запускает перерисовку верхнего текстового блока.
3. **Фоновый запрос (`withContext(Dispatchers.IO)`)** — выполнение переключается в поток ввода-вывода (`IO`), где вызывается функция `fetchGet(city)`.
4. **Формирование URL (`fetchGet`)** — адрес запроса собирается из нескольких частей:
    * `host` — задаёт адрес сервера ("https://" + "api." + "open-meteo.com").
    * `path` — указывает раздел прогноза погоды (`/v1/forecast`).
    * `params` — подставляет координаты города (`city.latitude`, `city.longitude`) и запрашивает текущие показатели (`temperature_2m`, `wind_speed_10m`, `precipitation`).
    * `apiUrl` — склеивает все части в единую ссылку, по которой открывается `HttpURLConnection` для получения JSON-ответа.
5. **Парсинг JSON и вывод результата** — из ответа извлекается объект `"current"`, откуда считываются температура (`temperature_2m`), скорость ветра (`wind_speed_10m`), осадки (`precipitation`) и время (`time`). Итоговая сводка записывается в `weatherText` и отображается на экране.
